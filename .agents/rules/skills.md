# Skills Usage Rule

## Always Utilize Relevant Installed Skills
Whenever the user asks for any task (including but not limited to frontend development, UI/UX design, security audits, code reviews, database operations, architecture design, debugging, testing, and deployment), always proactively check and apply the relevant skills installed in the system.

### Skill Categories & Triggers
- **Frontend & UI Engineering**: Use `frontend-design`, `frontend-ui-engineering`, `ux-design-systems`, `mobile-responsiveness`, and `web-accessibility` to build polished, responsive, accessible, and modern interfaces.
- **Security & Hardening**: Use `security-best-practices`, `security-and-hardening`, `owasp-security`, `muku-*`, `somar-pt-*`, `brss-*`, and `yak-*` when auditing, securing endpoints, reviewing auth, or handling untrusted input.
- **Code Quality & Testing**: Use `code-review-and-quality`, `test-driven-development`, `api-test-suite-builder`, and `code-simplification` to ensure clean, reliable, well-tested code.
- **Database & Architecture**: Use `database-designer`, `database-schema-designer`, `sql-database-assistant`, `mongodb`, `supabase`, `supabase-postgres-best-practices`, and `arch-lens`.
- **Debugging & Recovery**: Use `debugging-and-error-recovery` and `bug-triage` for systematic root-cause analysis.
- **Planning & Documentation**: Use `planning-and-task-breakdown`, `spec-driven-development`, `prd-to-github-issue`, and `documentation-and-adrs`.
